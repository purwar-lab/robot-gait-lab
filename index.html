Supported commands: Servo ...;, attach(), write(), delay(), integer/float variables, assignments, and simple arithmetic. Unsupported code such as if, for, custom functions, and sensor reads will trigger a clear error instead of a fake simulation.
This educational kinematic visualizer uses two 140-unit links. Playback interpolates toward servo targets during delays; it does not model physical servo speed or ground contact. The small panels project the same recorded 3D foot path onto XY, XZ, and YZ. Orange marks the foot; teal and purple mark the thigh and shin.
